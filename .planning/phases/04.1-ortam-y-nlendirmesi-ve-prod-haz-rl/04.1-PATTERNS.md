## Pattern Assignments

### `src/grispi/client/environment.ts` (YENİ — config/utility)

**Analog:** Dış-repo referans (RESEARCH.md satır 136-152), proje-içi emsali yok — dizin (`src/grispi/client/`) ve sabit-ihraç stili `http-handler.ts`'in üst kısmındaki `class`-dışı export deseniyle (`export class NetworkError extends Error {...}`, `export class HttpError`) tutarlı tutulmalı: her export tek bir sorumluluk, JSDoc yorumları proje genelinde her export'un üstünde (bkz. `grispi.type.ts`'teki yoğun JSDoc konvansiyonu).

**Tam içerik (RESEARCH.md'den birebir, değişiklik gerekmez):**
```typescript
export const GRISPI_BASE_URLS = {
  preprod: "https://api.grispi.net",
  prod: "https://api.grispi.com",
  prod_tr: "https://api.grispi.com.tr",
} as const;

export type GrispiEnvironment = keyof typeof GRISPI_BASE_URLS;

export const DEFAULT_ENVIRONMENT: GrispiEnvironment = "prod";

export const isGrispiEnvironment = (
  value: unknown
): value is GrispiEnvironment => {
  return typeof value === "string" && value in GRISPI_BASE_URLS;
};
```

**Proje konvansiyonu notu:** Bu dosyada `@/` alias'a ihtiyaç yok (bağımlılıksız saf sabitler) — `src/grispi/client/http-handler.ts` da aynı şekilde hiçbir import'a sahip değil (satır 1-9, sadece kendi `class` tanımları).

### `src/grispi/client/http-handler.ts` (DEĞİŞİR — service)

**Mevcut hal (satır 26-30):**
```typescript
export class HttpHandler {
  baseUrl: string = "https://api.grispi.net";
  headers: Record<string, string> = {
    "Content-Type": "application/json",
  };
```

**Uygulanacak değişiklik** (RESEARCH.md satır 194-213, import + alan varsayılanı + iki yeni metod):
```typescript
import {
  DEFAULT_ENVIRONMENT,
  GRISPI_BASE_URLS,
  GrispiEnvironment,
} from "./environment";

export class HttpHandler {
  baseUrl: string = GRISPI_BASE_URLS[DEFAULT_ENVIRONMENT];
  headers: Record<string, string> = { "Content-Type": "application/json" };

  setBaseUrl(baseUrl: string) {
    this.baseUrl = baseUrl;

  setEnvironment(environment: GrispiEnvironment) {

  // send / sendMultipart değişmeden kalır (satır 32-87)
}
```

### `src/contexts/plugin-bootstrap.ts` (DEĞİŞİR — controller)

**Analog:** Kendisi — mevcut `BootstrapPluginInitDeps` arayüzü ve `bootstrapPluginInit` fonksiyonu (tam dosya yukarıda okundu, 65 satır).

**Mevcut deps arayüzü deseni** (satır 28-44) — her yeni bağımlılık bu listeye eklenir, fonksiyon-tipi alan olarak (state setter'lar `set<Alan>(value)` imzasında):

**Mevcut orkestrasyon sırası** (satır 49-58) — `try` bloğu içinde senkron zincir, `switchTicket` HER ZAMAN son çağrılan adım:
```typescript

    const bundle = await deps.plugin._init();

    deps.authentication.setTenantId(bundle.context.tenantId);
    deps.authentication.setToken(bundle.context.token);
    deps.setTenantId(bundle.context.tenantId);
```
