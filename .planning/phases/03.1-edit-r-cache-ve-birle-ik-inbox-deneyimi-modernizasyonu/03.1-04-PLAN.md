<interfaces>
Create a discriminated immutable envelope with these required fields:

```typescript
export type MutationEnvelope =
  | {
      kind: "create";
      clientMessageId: string;
      tenantId: string;
      parentKey: string;
      sideKey?: undefined;
      request: CreateTicketRequest;
      sessionKey: number;
      startedAt: number;
    }
  | {
      kind: "reply";
      clientMessageId: string;
      tenantId: string;
      parentKey: string;
      sideKey: string;
      request: ReplyTicketPatchRequest;
      sessionKey: number;
      startedAt: number;
    }
  | {
      kind: "solve" | "reopen";
      clientMessageId: string;
      tenantId: string;
      parentKey: string;
      sideKey: string;
      request: StatusTicketPatchRequest;
      sessionKey: number;
      startedAt: number;
    };
```

MobX transitions required by the Query callback boundary:

```typescript
mutationStarted(envelope: MutationEnvelope): void;
mutationFailed(envelope: MutationEnvelope, kind: "network" | "server"): void;
bindCreatedTicket(envelope: MutationEnvelope, sideKey: string): void;
mutationAccepted(envelope: MutationEnvelope): void;
reconcileCanonical(sessionKey: number, sideKey: string, messages: MessageVM[]): void;
getRetryEnvelope(clientMessageId: string): MutationEnvelope | null;
```

Canonical comments keep `comment-${comment.id}` IDs. Lifecycle status remains server-authoritative (`SOLVED="4"`, `OPEN="2"`); PATCH responses never replace canonical GET data.
