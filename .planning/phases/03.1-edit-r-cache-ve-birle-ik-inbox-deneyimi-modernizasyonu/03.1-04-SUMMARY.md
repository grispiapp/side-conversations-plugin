## Decisions Made

- Kept request identity as a runtime invariant, not only a TypeScript convention: recursive freezing covers the envelope, request, comment, creator tuple, fields array, and field entries.
- Let Query mutation executors own the complete asynchronous callback sequence so UI components only construct/route envelopes and cannot accidentally accept stale PATCH responses.
- Used `refetchType: "all"` for exact parent-list invalidation so inactive parent caches are refreshed, and exact `type: "all"` detail refetch with thrown refresh errors so acceptance cannot use silently stale canonical state.
- Used a nullable `ticketKey` only for the pending-create selected session; every reply/status action still requires a concrete exact side key.
- Preserved local pending-create recipient/subject only as session presentation, never as canonical thread state.
