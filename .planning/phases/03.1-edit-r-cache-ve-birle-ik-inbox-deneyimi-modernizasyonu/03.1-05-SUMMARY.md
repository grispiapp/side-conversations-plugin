## Decisions Made

- Used one visible trailing `Yeni görüşme` action in the list header instead of an icon-only or floating CTA.
- Kept queue status as compact text rather than visually heavy cards/pills; the unseen rail remains spatially independent and receives explicit `Görülmemiş` wording.
- Preserved a single-row toolbar with contained local horizontal scrolling because nine 44px commands cannot fit simultaneously inside the 372px surface without shrinking targets or creating screen overflow.
- Kept all Query/MobX ownership, envelopes, refresh ordering, and session gates unchanged; UI components only changed presentation, accessible interaction, and meaningful compose validation.
