## Trust Boundaries

| Boundary | Data Crossing | Verified Controls |
|---|---|---|
| Clipboard/remote API → DOMPurify/Tiptap/rendered DOM | Untrusted HTML | Explicit DOMPurify policy; untrusted paste/restore strips the first inherited quote and everything after it (including spoofed quote markers); canonical normalization keeps separately sanitized authored/history parts; sinks re-sanitize both parts; one public-only canonical history block is appended on reply |
| Tiptap/store draft → Grispi create/reply payload | User-authored HTML | Only editor-admitted content reaches trusted-authored setters; create and reply stores independently sanitize immediately before constructing and freezing their outbound envelopes |
| Grispi SDK/standalone config → React context | Tenant, token, agent, ticket identity | Tenant published from the authenticated bundle/config and cleared from React context on bootstrap failure |
| React context/resource identifiers → Query cache/API | Tenant, parent, side and customer-search identifiers | Exact tenant-scoped keys, enabled gates, finite read policy |
| List row → selected thread session | Side key, parent key, session identity, focus target | Synchronous tuple capture and monotonic session key |
| UI/MobX envelope → Query mutation → Grispi | Create, reply and lifecycle request objects | Recursively frozen envelopes, Query-only transport, selected-session gates |
| Grispi canonical GET → local overlays | Message body, authored/history provenance, creator, timestamp, canonical ID | Structured sanitized authored/history normalization plus sanitized compound match, lower time bound and FIFO one-to-one reconciliation |
| Query/MobX state → accessible DOM | Recipient, subject, status, message HTML | Exact selected data, explicit labels/states, sanitized message rendering |
| Keyboard/focus → navigation and lifecycle actions | Menu, dialog, discard and lifecycle intent | Semantic controls, Escape/outside handling, safe initial focus and focus return |
| Package manifests/locks → production dependency graph | Editor, sanitizer and Query packages | Exact committed pins and no plan-time-to-HEAD package-file changes |
