<the_central_hazard>

**This is NOT a find-replace.** Turkish vowel harmony: `görüşme` is a
front-vowel (*ince*) stem; `yazışma` is a back-vowel (*kalın*) stem. Their
suffixes therefore differ.

<!-- planner-discipline-allow: görüşme -->
<!-- planner-discipline-allow: örüşme -->
<!-- planner-discipline-allow: yazışmaler -->
<!-- planner-discipline-allow: yazışmeyi -->
<!-- planner-discipline-allow: yazışmeler -->
<!-- planner-discipline-allow: yazışme -->
<!-- planner-discipline-allow: yazışmey -->

| Current form | Correct replacement | What a naive stem swap produces |
|---|---|---|
| görüşme | yazışma | correct — the bare form is the only safe one |
| görüşme**ler** | yazışma**lar** | WRONG: "yazışmaler" |
| görüşme**yi** | yazışma**yı** | WRONG: "yazışmeyi" |

Case-preserved, the complete six-way mapping is:

| Find | Replace |
|---|---|
| `Görüşme`   | `Yazışma`   |
| `görüşme`   | `yazışma`   |
| `Görüşmeler`| `Yazışmalar`|
| `görüşmeler`| `yazışmalar`|
| `Görüşmeyi` | `Yazışmayı` |
| `görüşmeyi` | `yazışmayı` |

**Two compounding traps:**

1. **Ordering.** The bare stem is a prefix of every inflected form. Swapping the
   bare stem first turns the plural into "yazışmaler".
2. **Case.** Title-case and lowercase forms coexist, sometimes in the same file.
   Casing must be preserved per occurrence.

**THE RULE THAT DEFUSES BOTH — replace whole quoted UI phrases, never the bare
stem.** Every table row in Tasks 1-3 gives a complete phrase as the search key.
Because a phrase carries its own suffix, the ordering trap cannot fire and the
casing is carried along in the literal. Do not, under any circumstance, run a
`replace_all` whose search key is the bare word alone.

**Do not trust this plan's inflection list as final.** Re-derive it from source
before editing (Task 0 command below) and grep for residuals after.

</the_central_hazard>
